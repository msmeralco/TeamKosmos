# Backup video checklist

Record twice: a rough take after Gate G1 and the final take after feature freeze.

## Before recording
- [ ] `python backend/scripts/demo_run.py` is green.
- [ ] Frontend is built (`npm run build` in `frontend`) and the backend serves it on one port.
- [ ] Prices and PVGIS caches are fresh.
- [ ] Browser zoom, notifications off, API keys hidden from the screen.
- [ ] Synthetic demo account is signed in.

## Chapters (match the demo script)
- [ ] 1. Hook and problem slides
- [ ] 2. Address, roof outline, one corner adjusted
- [ ] 3. Chat: bill, budget, goal, live product feed, three packages
- [ ] 4. ROI table, net-metering toggle, range and cash-flow chart
- [ ] 5. Math drawer
- [ ] 6. Passport issue, QR, verify page, tamper test
- [ ] 7. Close

## After recording
- [ ] Each chapter starts at a known timestamp.
- [ ] Plays on the presentation laptop with no network.
- [ ] A copy is on a USB drive and on the laptop desktop.
